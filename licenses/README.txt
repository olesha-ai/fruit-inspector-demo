Fruit Inspector evaluation package — licenses
=============================================
This folder MUST ship inside every release zip next to Fruit_Inspector.exe.

olesha-ai does NOT own Intel OpenVINO, ONNX Runtime, YOLOX, LightGBM, etc.

Fruit_Inspector_LICENSE.md

  optional trig.exe, models in model/ (testing / students / research only).
  Commercial production line use requires a separate written agreement.
